微博超话签到：青龙安卓适配包

文件说明
1. chaohua_sign_android.py：上传到青龙“脚本管理”根目录的脚本，不含个人登录凭据。
2. status_taobudiao.txt：从用户提供的 HAR 中提取的完整列表请求链接，含登录凭据，仅粘贴到自己的青龙环境变量；不要上传 GitHub 或分享本压缩包。

配置步骤（已安装青龙）
1. 依赖管理 → Python3 → 新建依赖 → requests，等待安装成功。
2. 脚本管理 → 上传 chaohua_sign_android.py；也可以新建同名文件，复制脚本全部内容后保存。
3. 环境变量 → 新建：名称 status_taobudiao；值复制 status_taobudiao.txt 的完整一行。不要加引号、export 或变量名=。保存后保持启用。
4. 定时任务 → 新建：名称 微博超话签到；命令 task chaohua_sign_android.py；定时规则 10 9 * * *。
5. 保存后手动运行一次，查看日志。正常会显示逐项结果以及成功、已签、失败、跳过的汇总。

定时规则按青龙运行环境时区执行。若时区为 Asia/Shanghai，上述规则为北京时间每天 09:10；若时区为 UTC，等效规则为 10 1 * * *。确认界面显示的下次运行时间。

本版本只需要这一个 Python 脚本与 requests，不依赖 notify.py。通知未接入，结果查看青龙任务日志。
只支持一个账号，读取 status_taobudiao；不用填写 weibo_my_cookie 或 status_tianqi。
不需要把 HAR 或凭据文本上传到脚本目录。
脚本只执行关注超话的签到，没有自动发微博功能。

验证范围
按 2026-09-22 安卓微博抓包适配：multipart 表单列表请求、GET 签到、返回游标分页（例如 -1_2）、已签跳过、请求超时与异常退出。
已用抓包响应进行离线测试：识别 5 个超话（其中 2 个已签），模拟 3 个待签到请求及下一页，检查参数构造与日志不含登录凭据。
没有发送真实微博请求；这不代表当前凭据、安卓接口或服务器网络已实测可用。需要在青龙手动运行验证。
抓包中实际签到请求返回 result=1、msg=已签到，这是抓包当时的结果。

常见问题
- No module named requests：在 Python3 依赖分类安装 requests。
- 提示环境变量为空：确认变量名完全一致、变量已启用、值为一条完整 URL。
- 缺少 items、非 JSON、401/403：可能是登录失效、验证要求或接口变化；先确认 App 正常，再重新抓取列表请求更新环境变量。
- 网络超时：检查青龙所在服务器到 api.weibo.cn 的网络。
- 分页重复或达到页数上限：脚本会报错退出，不会把未完成误报成全部成功。
- 有失败或跳过：查看对应超话并手动核实，可提供日志继续排查；不要公开完整抓包或凭据。
